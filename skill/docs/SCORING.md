# 打分规则（v0.1）

打分只依赖：提交的 `text`、测试集标注、热词文件。不依赖任何模型框架。

## 1. ASR 模式（`--task asr`）

对每条样本，用 `variant` 查热词里的读音/表面形态，再检查转写：

### 正样本
- **严格档（strict）**：满足任一
  - 转写里出现该 variant 的读音（假名，考虑长音归一），且按词边界对齐；
  - 转写里出现该 variant 的可接受表面形态（如 `アフターグロウ`、`夢限大みゅーたいぷ`）。
- **宽松档（lenient，默认主指标）**：严格档之外再接受
  - 该组的规范写法（`neg_check_forms`，如 `MyGO` / `アヴェムジカ` / `夢限大`）；
  - 读音长度 ≥3 时的长音/促音小差异、子串命中；
  - 英文名忽略空格/大小写（`Poppin'Party` ≈ `Poppin Party`）。

### 负样本
- 若转写里出现该组**无歧义专名形态**（`neg_check_forms`/`name_forms_ja` 中的规范形态）→ **过触发（错）**；
- 同音普通词（`無限大`、`夢見た`、`迷子`、`湯の`、`確率`、`レイズ` 等不在判定表里）不算专名；
- 词内子串不算（`ブレイズ` 不会命中 `レイズ`）；
- 空转写记为 `empty`，不算 neg 通过。

## 2. 同传模式（`--task zh`）

### 正样本
- **严格档**：中文输出包含该样本 `allowed_zh` 中任意一项（也接受 `hotwords/zh_hotwords.json` 里该 variant 的等价译名）；
- **宽松档**：额外接受该组规范译名/别名（`aliases`）。

### 负样本
- 中文输出不得包含该组 `name_forms_zh` / 规范中文译名（如「梦限大」「阿拉蕾」）；
- 空输出记为 `empty`，不算通过。

## 3. 汇总指标

| 指标 | 含义 |
|---|---|
| `pos_rate` | pos 命中率（宽松），主指标 |
| `pos_strict_rate` | pos 严格命中率 |
| `neg_rate` | neg 未误触发率 |
| `neg_over` | neg 出现专名的条数 |
| `empty` | 空输出条数（单独报告） |

分组指标按 `group` 输出（17 组），便于定位人名/乐队名的弱项。

## 4. 标签与标注噪声

- 只有一套测试集；val 不对外。
- `pos` 标签错误率低但非零（抽样人工复核 + 多模型一致性检查）；
  若你发现「音频里明显不是这个名字」，请附 `sample_id` 反馈 l_a@live.cn。
- `neg` 的 `difficulty=easy` 是子词/普通词近音（如 あられ vs あらし），`hard` 是上下文裁决后的同音难例。
