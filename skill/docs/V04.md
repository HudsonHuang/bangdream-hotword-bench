与 v0.1 的 283 条句级切片不同，这里只有一条 41 分钟音轨和一份自动字幕单元。

## 口径

- **不是人工金标**：参考文本来自 YouTube 自动字幕，可能有错字/漏句；适合查“律/由乃”这类明显回归，不适合当 BLEU 金标。
- **不切片**：整条 41 分钟 1x 回放，能暴露长时间会话里的热词漂移。
- **mention 自动标注**：`units.jsonl` 的 `mentions` 由已知名字变体匹配得到；Mujica/MyGO 名字若自动字幕没写出来，就不会出现在参考里，需要人工补。

## 跑法

```powershell
python tools/replay_stream.py --wav v0.4-full/audio16k.wav --out runs/v04 -- `
  --source-language ja --target-language zh `
  --model qwen-audio-3.1-asr-flash-streaming --max-end-silence 200 `
  --vad-model near_meeting_16k --mt-model qwen3.8-max --mt-mode reference `
  --hotwords hotwords/yumemita_bangdream_no_ritsu.txt

python <bench>/skill/scripts/eval_v04.py --run runs/v04/events.jsonl --out runs/v04/name_eval.jsonl
```
