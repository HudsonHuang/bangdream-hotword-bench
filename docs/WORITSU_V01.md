# woritsu_v0.1 · 不带律场景组合测试集

由三部分组成：

- **v0.3**：32 条人工精标高光（92.4 分钟），唯一有人工中文 SRT 的子集；
- **v0.4**：40:56 完整直播不切片（自动字幕 471 unit），测长时间人名回归；
- **v0.5**：野乃花两段（晾衣服 106 秒 + 魔女裁判 50:20 110 秒）。

## 口径

- v0.3 用 `eval_stream.py`：coverage / first-zh / charF1 / BLEU / 人名召回 / 成本；
- v0.4 用 `eval_v04.py`：自动参考的 mention 召回、误替换；自动字幕稀疏，不作为 BLEU 金标；
- v0.5 用统一 worker 回放，重点查律/由乃/千石由乃，以及草稿是否真的触发。

## 本轮优化

1. 词表：去掉短律，保留峰月律；加 `のちゃん => 野乃花`、`戦国ゆの => 千石由乃`、Mujica/祥子/睦/初华/海铃/喵梦/小灯；
2. 草稿：新增 `--draft-after-chars`，partial 到 16 字就发草稿，不再只等 4 秒；
3. 约束：没有新增调用类型；草稿仍是原有 DeepSeek 调用，成本增量在 10% 内。
